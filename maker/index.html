App 工坊

選一個 HTML 檔和一張圖，按「做成 App」，它就會上傳到你的 GitHub，最後給你網址。用 Safari 打開網址，就能加到主畫面。

1程式檔

</>
選擇 HTML 檔Claude 給你的 .html 檔都可以

2圖示

圖
選擇一張圖片會自動裁成正方形
沒有圖片時，用文字當圖示：

3名稱與網址

網址會是：https://你的帳號.github.io/專案名稱/

專案名稱跟已經做過的 App 一樣，就會更新那個 App；不一樣就會新開一個專案。

4GitHub 連線

尚未設定
  1. 打開 建立權杖的頁面（會自動勾好 repo 權限）
  2. Expiration 選 No expiration（或你想要的期限）
  3. 拉到最下面按 Generate token
  4. 複製 ghp_ 開頭那串，貼到上面

權杖就像密碼，不要給別人。只會存在這台裝置的瀏覽器裡，也只會送到 GitHub。

進度

    完成了！

    打開看看

    1. 用 Safari 打開網址
    2. 按下方「分享」
    3. 選「加入主畫面」，再按「新增」
