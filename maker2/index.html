HTML➡️APP

選一個 HTML 檔和一張圖，按「做成 App」，它就會上傳到你的 GitHub，最後給你網址。用 Safari 打開網址，就能加到主畫面。
1

程式檔

選擇 HTML 檔，Claude 給你的 .html 檔都可以。

點這裡選擇 HTML 檔會自動讀出 App 的名字
2

準備圖片

選一張你喜歡的圖片做為 App 的圖示，會自動裁成正方形。

點這裡選擇圖片JPG、PNG 都可以
沒有圖片時，用文字當圖示：
你的 App
3

名稱與網址

網址會是：https://你的帳號.github.io/專案名稱/

專案名稱跟做過的 App 一樣，就會更新那個 App；不一樣就會開一個新的。

4

GitHub 連線

第一次使用要先連上你的 GitHub，之後就會自動跳過這一步。

  1. 打開 建立權杖的頁面（權限會自動勾好）
  2. Expiration 選 No expiration
  3. 拉到最下面按 Generate token
  4. 複製 ghp_ 開頭那串，貼到下面

權杖就像密碼，不要給別人。只存在這台裝置，也只會送到 GitHub。
